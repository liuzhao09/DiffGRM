# Contributing to DiffGRM

Thank you for your interest in improving DiffGRM. Bug reports, documentation fixes, and focused pull requests are welcome.

## Before Opening a Pull Request

1. Open an issue for substantial changes so the approach can be discussed first.
2. Keep changes focused and document any new configuration options or dependencies.
3. Verify that you have the right to submit all code, data, and other material in the contribution.
4. Do not include proprietary data, credentials, private checkpoints, or material whose license is incompatible with this repository.

## Contribution Terms

By submitting a contribution, you represent that you are legally entitled to provide it and that you license your contribution under the same [CC BY-NC 4.0 license](LICENSE.md) that applies to this repository, without additional terms or restrictions.

If a contribution contains or is derived from third-party material, preserve all required notices and clearly identify its source and license in the pull request. Acceptance of a contribution does not override any third-party rights or terms.

## Reporting Issues

Please include the dataset category, command-line arguments, relevant configuration, environment information, and a minimal error log when reporting a reproducibility problem. Do not attach third-party datasets or other restricted material to an issue.
